# Task Manager

Простое приложение для создания задач на PyQt6.

## Запуск

Установите PyQt6:

```bash
pip install PyQt6
```

Запустите приложение:

```bash
python main.py
```

## Возможности

- Ввод названия задачи.
- Ввод описания.
- Выбор приоритета Low, Medium или High.
- Настройки Important и Send notification.
- Кнопка Create task показывает результат в окне и выводит его в консоль.
- Кнопка Clear очищает форму.
- Статус показывает состояние приложения.

## Использованные элементы

- `QMainWindow` — главное окно.
- `QWidget` — центральный виджет.
- `QVBoxLayout` и `QHBoxLayout` — расположение элементов.
- `QLineEdit` — название задачи.
- `QTextEdit` — описание и результат.
- `QRadioButton` — выбор одного приоритета.
- `QCheckBox` — дополнительные настройки.
- `QPushButton` — кнопки.
- `QLabel` — подписи и статус.
