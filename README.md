# Task Manager

## Описание

Это простое приложение для создания задач, написанное на Python с использованием PyQt6.

## Что умеет приложение

- Вводить название задачи.
- Добавлять описание задачи.
- Выбирать приоритет: Low, Medium или High.
- Отмечать Important и Send notification.
- Создавать задачу кнопкой Create task.
- Смотреть результат в окне приложения.
- Очищать поля кнопкой Clear.
- Видеть статус приложения.

## Какие элементы использованы

- QMainWindow - главное окно.
- QWidget — центральная часть окна.
- QVBoxLayout и QHBoxLayout — расположение элементов.
- QLineEdit — ввод названия задачи.
- QTextEdit — описание и результат.
- QRadioButton — выбор приоритета.
- QCheckBox — дополнительные настройки.
- QPushButton — кнопки Create task и Clear.
- QLabel — подписи и статус.
